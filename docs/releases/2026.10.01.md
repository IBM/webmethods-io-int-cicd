# October 2026 Release: DADA + Gen1/Gen2 Support

Source: feature/gen1-gen2-support. Tag: 2026.10.01.

Includes DADA Phase 1 and generation-aware authentication through the shared curl wrapper. Gen1 remains the default and retains Basic Auth. Gen2 tenant requests use the secret INSTANCE_API_KEY in x-instance-api-key. Non-tenant requests retain their original authentication.

Includes pipeline integration for initialization, runtime registration, export, DEV import, and QA import; API success-response handling; SOAP failure propagation; API-aware project creation; configuration-export validation and reuse; empty-package handling and package-API fallback; and external-Git projects without imported packages.

Set tenant.generation in environment configuration and supply the appropriate secret pipeline variable. Direct callers must configure the wrapper PATH and environment too. See README_EXTENSION_2.md for details.

This is a separate feature-branch snapshot, not a merge of main. Validation is local and offline; no live tenant results or universal cross-generation asset compatibility are asserted by these notes.
