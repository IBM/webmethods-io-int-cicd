##### October 2026 Release ########
Technical releases:
- 2026.10 (main): DADA Phase 1 with existing Gen1 authentication.
- 2026.10.01 (feature/gen1-gen2-support): DADA plus Gen1/Gen2 authentication.
The configuration-export fixes in 3.d–3.f apply to the Gen1/Gen2 release.

1. DADA (Develop Anywhere, Deploy Anywhere) Phase 1
    a. Project initialization with external Git and an existing user-owned Git connection alias.
    b. Imported custom-package metadata export and package import before dependent project assets.
    c. Product-owned scaffolding and project mapping preserved for external-Git projects.
    d. Imported-package metadata from the Configurations API for internal-Git projects.
    e. Explicit project Git-mode configuration and environment-specific package branch mappings.
    f. Compatibility handling for older projects without explicit Git-mode metadata.
    g. Wrapper integration in initialization and runtime registration pipelines.
2. Gen1 / Gen2 tenant support
    a. Shared curl wrapper selects authentication using tenant.generation, defaulting to Gen1.
    b. Gen1 retains Basic Auth; Gen2 tenant requests use the secret INSTANCE_API_KEY through x-instance-api-key.
    c. Non-tenant requests retain their original authentication.
    d. Wrapper integration in export, DEV import, and QA import pipelines.
3. Bug fixes
    a. API import handles message/status success response variants.
    b. Detect exported REST/SOAP APIs before destination project creation during full synchronization, allowing API import to create the project.
    c. Propagate SOAP API import failures, missing export files, and directory-change failures to the caller.
    d. Validate project configuration responses before saving exports; preserve existing valid exports when requests fail and remove previously generated invalid configuration artifacts.
    e. Reuse valid exported project configuration for DADA metadata instead of querying it again.
    f. Treat missing/null package configuration as an empty package list and fall back to the package API when the Configurations API does not return a usable payload.
    g. Skip package import for external-Git projects with no imported-package metadata; report missing scaffolding when other DADA metadata is present.
